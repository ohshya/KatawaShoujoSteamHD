**Steam 版『かたわ少女』を 1920×1080 のワイド画面で。R18 も収録。**

Four Leaf Studios のビジュアルノベル **『かたわ少女』（Katawa Shoujo）** の Steam 版を、本来の 800×600（4:3）
ではなく **フル HD（1920×1080、16:9 ワイド）** で動かす非公式のファンパッチです。背景、キャラクターの立ち絵、CG、
インターフェース、動画を HD 版に置き換えます。Steam 版の Ren'Py 6.16 エンジンで、全 11 言語に対応しています。

**[最新版をダウンロード](https://github.com/ohshya/KatawaShoujoSteamHD/releases/latest)**

> 本パッチは **letow** 氏の [Katawa Shoujo HD Patch](https://github.com/letow/KatawaShoujoHDPatch) を移植したものです。
> HD のアートワーク（背景、立ち絵、CG、UI、エフェクト、動画）はすべてそのプロジェクトのものです。クレジットの
> 詳細は最後にあります。

## このエディションの新機能

オリジナルの HD パッチにはない、このエディション独自の内容です。

- **Steam 版の全 11 言語。** オリジナルのパッチは英語、スペイン語、フランス語、日本語に対応し、ドイツ語と
  ロシア語は追加分でした。このエディションでは韓国語、ポーランド語、ブラジルポルトガル語、簡体字中国語、
  繁体字中国語を追加し、各言語の R18 シーンにも対応しています。オリジナルのパッチになかったポーランド語の
  コミック風パネル 4 枚（`comic_vfx*_pl`）も、ほかの言語と同じ方法で HD 化しました。
- **Steam 版への対応。** HD 用の調整（解像度、位置、ズーム、パン、UI レイアウト）を Steam 版のスクリプトを
  置き換えるのではなく、その上から適用しています。そのため実績、コントローラー対応、R18 の切り替え、パック
  された言語ファイルといった Steam 版の機能はそのまま使えます。
- **HD 版の R18 パッチ。** `r18-hd.rpa` が公式の `r18.rpa` を置き換え、同じシーンを HD で収録しています。
- **スクロールできる言語選択画面。** HD レイアウトのまま、11 言語すべてが収まるようにスクロールします。
- **画面に合わせたウィンドウ。** ゲームはデスクトップの作業領域（タスクバーとタイトルバーを除く）の 90% の
  大きさで、中央にウィンドウ表示されます。サイズは 1280×720 から 1920×1080 の間で、画面より大きくなることは
  ありません。フルスクリーンは従来どおり使えます。
- **より新しいゲームのベース。** 『かたわ少女』1.3/1.3.1 ではなく、現在の Steam 版のスクリプト（v1.3.2）を
  ベースにしているため、その後のゲームの修正もそのまま残ります。
- **個別ファイルではなくアーカイブで配布。** HD 素材は 2 つの `.rpa` アーカイブにまとめているので、パッチの
  導入と削除はファイルを追加・削除するだけです。

## 概要

オリジナルの HD パッチは、成人向けコンテンツをゲーム本体に含む『かたわ少女』StandAlone 版（Ren'Py 6.10）向けに
作られました。Steam 版はより新しい Ren'Py（6.16.5）で動作し、そのコンテンツをオリジナルの 4:3 のアートの
まま別の R18 パッチ（`r18.rpa`）に分け、独自の機能も追加しています。そのため、オリジナルのパッチを Steam 版に
適用するとゲームがクラッシュします。

このエディションは、同じ HD リマスターを Steam 版で使えるようにし、R18 パッチも HD で収録しています。

### 見た目の変更

このエディションはコードの移植のみで、見た目の変更は加えていません。ゲームの見た目はオリジナルの HD パッチと同じです。変更前と変更後の比較は[オリジナルの Katawa Shoujo HD Patch のリポジトリ](https://github.com/letow/KatawaShoujoHDPatch)をご覧ください。

## 対応言語

英語、スペイン語、フランス語、日本語、ドイツ語、韓国語、ポーランド語、ブラジルポルトガル語、ロシア語、
簡体字中国語、繁体字中国語：Steam 版の全 11 言語です。

## インストール

インストーラーは不要です。

> **パッチは [Releases](https://github.com/ohshya/KatawaShoujoSteamHD/releases/latest) ページからダウンロード
> してください。** リポジトリにはビルドツールが入っており、HD アーカイブ（約 660 MB の `patch-hd.rpa` と
> `r18-hd.rpa`）はリリースの zip にのみ含まれています。

1. 最新リリースから [`KS-HD-1.0.1-Steam-Patch.zip`](https://github.com/ohshya/KatawaShoujoSteamHD/releases/download/v1.0.1/KS-HD-1.0.1-Steam-Patch.zip) をダウンロードします。
   遊ぶのに必要なのはこのファイルだけです。もう一方の `Assets-For-Building-Only` は、パッチを自分で
   ビルドする場合にのみ使います。
2. Steam で **Katawa Shoujo** を右クリックし、**管理** > **ローカルファイルを閲覧** を選びます。
3. zip をそのフォルダ（`Katawa Shoujo.exe` があるフォルダ）に展開します。
4. 確認されたら **すべてのファイルを置き換える** を選びます。
5. Steam からゲームを起動します。

**Linux と macOS：** パッチが置き換えるのはゲームデータ（スクリプトとアーカイブ）だけで、これはどのシステム
でも同じです。Linux では手順は同じです。macOS では、**ローカルファイルを閲覧** でゲームのアプリがある
フォルダが開きます。アプリを右クリックして **パッケージの内容を表示** を選び、zip の `game` フォルダを中の
`game` フォルダに統合してください。

公式の `r18.rpa` は不要です。すでにフォルダにある場合はそのままで構いません。ゲームは HD 版を使います。

**アンインストール：** `game/patch-hd.rpa` と `game/r18-hd.rpa` を削除し、Steam で
**プロパティ** > **インストール済みファイル** > **ゲームファイルの整合性を確認** を実行します。

> Steam のアップデートでパッチを当てたスクリプトが上書きされることがあります。その場合はパッチをもう一度
> 展開してください。

> **Steam の通常のブランチを使ってください。** このパッチはゲームのメインのバージョン（Ren'Py 6.16）向けです。
> ベータ版の **modern - Ren'Py 8 branch** にはまだ対応していません。選択している場合は、パッチを導入する前に
> **プロパティ** > **ベータ** で通常のブランチに戻してください。Ren'Py 8 ブランチへの対応は現在進めています。

### リリースの zip の中身

| ファイル | 内容 |
|---|---|
| `game/patch-hd.rpa` | HD の背景、立ち絵、CG、UI、エフェクト、動画。 |
| `game/r18-hd.rpa` | HD 版の R18 パッチ。公式の `r18.rpa` を置き換えます。 |
| `game/*.rpyc` | HD レイアウトの調整を加えた Steam 版のゲームスクリプト（全 11 言語）。 |
| `game/presplash.png` | HD パッチのロード画面。 |

## よくある質問

**Steam の「modern - Ren'Py 8 branch」で使えますか？**
まだ使えません。対応は現在進めています。パッチは通常のブランチ（Ren'Py 6.16）向けで、Ren'Py 8 のベータは
スクリプトの形式が異なるため、そこに導入するとゲームが壊れます。

**公式の R18 パッチ（`r18.rpa`）は必要ですか？**
いいえ。`r18-hd.rpa` に R18 シーンが HD で含まれており、ゲーム内でそれをオフにするオプションも使えます。

**letow 氏の Katawa Shoujo HD Patch と同じものですか？**
同じ HD アートとシーンの調整を Steam 版に移植したもので、さらに「このエディションの新機能」に挙げた変更を
加えています。letow 氏のオリジナルのパッチは StandAlone 版向けで、Steam 版ではクラッシュします。

**Linux、macOS、Steam Deck で使えますか？**
使えるはずです。パッチが変更するのはゲームデータだけで、これはどのシステムでも同じです。ただし現時点では
Windows でしかテストしていないので、報告を歓迎します。

**元のゲームに戻すには？**
`game/patch-hd.rpa` と `game/r18-hd.rpa` を削除し、Steam で **ゲームファイルの整合性を確認** を実行します。

## ソースからのビルド

このリポジトリには、パッチを生成するコードが入っています。データとして保存した HD の変更点と、それを
お手元のゲームのコピーに適用するツールです。ゲームのファイルと HD のアートは含まれていません。

このツールは透明性のためのもので、パッチが何を変更するのかを誰でも正確に確認し、再ビルドできるように
しています。HD パッチの移植には、『かたわ少女』StandAlone 版、Steam 版、公式の `r18.rpa`、StandAlone 版用の
HD パッチから情報を抽出し、それらを比較して HD パッチの変更点をすべて洗い出す必要がありました。抽出用の
モジュールは一度しか使わないため含めておらず、その結果を `kshd/edits` に保存しています。

### AI の利用

移植作業そのものは長く雑然としたもので、使い捨てのテストコードや試行錯誤が大量に生まれました。その過程で
手作業で書いた元のツールを公開するのは現実的ではなく、意味もありませんでした。そこでこのリポジトリの
ビルドツールは、移植で得られたデータからパッチをきちんと確実にビルドできるよう、Anthropic の
**Claude（Opus 5.5）** を使って作成しました。

### 必要なもの

- [Python](https://www.python.org/) 3.9 以降。追加のパッケージは不要です。
- Steam 版『かたわ少女』（**未改変**で、通常のブランチのもの。Ren'Py 8 のベータは不可）。
- HD 素材パッケージ：[`KS-HD-1.0.1-Assets-For-Building-Only.zip`](https://github.com/ohshya/KatawaShoujoSteamHD/releases/download/v1.0.1/KS-HD-1.0.1-Assets-For-Building-Only.zip)（約 700 MB）。

### ビルド

1. このリポジトリをクローンするか、ダウンロードします。
2. 次のどちらかの方法で、ツールがゲームを読み込めるようにします。
   - **リポジトリ内にゲームのコピーを置く：** ゲームのフォルダ（`Katawa Shoujo.exe` があるフォルダ）を
     リポジトリの直下にコピーし、名前を `Katawa Shoujo` にします。パッチを導入する前のコピーを使ってください。
     この方法なら、Steam のインストールにパッチを当てたままビルドできます。
   - **Steam のインストールを使う：** リポジトリにコピーがない場合、ツールは Steam のライブラリからゲームを
     探します。すでにそこにパッチを導入している場合は、先に Steam で **ゲームファイルの整合性を確認** を
     実行してください。
3. `KS-HD-1.0.1-Assets-For-Building-Only.zip` を `assets` フォルダに置きます（zip のままでも展開しても
   構いません）。
4. 次を実行します。

```bash
python build.py
```

ツールがスクリプトにパッチを当て、`build.py` と同じ場所に `KS-HD-1.0.1-Steam-Patch.zip` を作成します。この zip が
パッチです。「インストール」の説明どおりに導入してください。

スクリプトがパッチの想定と一致しない場合、ビルドは止まり、どのスクリプトかを表示します。これはゲームの
ファイルが改変されているか、別のバージョンのものである場合に起こります。

### 仕組み

HD パッチがゲームのスクリプトで変更するのは、解像度、位置、ズーム、パン、インターフェースのレイアウトと、
「このエディションの新機能」で説明したウィンドウのサイズだけです。これらの変更は、スクリプトごとに 1 つの
JSON ファイルとして、読める形のデータで `kshd/edits` に保存しています。

- **`code`**：インターフェースのコードの置き換え。それぞれに元のテキストと出現すべき回数を記録しており、
  違うバージョンのゲームに誤ってパッチを当てずに検出できます。
- **`nodes`**：シーンの命令（`show`、`scene`、ATL トランスフォーム）の変更。ラベルと元の内容で場所を特定する
  ため、同じファイルで全 11 言語に対応できます。

| ファイル | 役割 |
|---|---|
| `build.py` | ゲームと素材を見つけ、スクリプトに並列でパッチを当て、パッチの zip を作成します。 |
| `kshd/edits/*.json` | データとしての HD の変更点。 |
| `kshd/patch.py` | 変更点のファイルをスクリプトに適用します。 |
| `kshd/tree.py` | スクリプトの構造をたどり、変更するコードと命令を見つけます。 |
| `kshd/rpyc.py` | コンパイル済みの `.rpyc` スクリプトを、Ren'Py 6.16 との互換性を保ったまま読み書きします。 |
| `kshd/rpa.py` | Ren'Py の `.rpa` アーカイブを読み書きします。 |

### HD 素材パッケージ

画像、動画、R18 シーンはコードとは別の素材パッケージにまとめており、コードに手を加えずに改良できるようにしています。HD のアートは letow 氏の [Katawa Shoujo HD Patch](https://github.com/letow/KatawaShoujoHDPatch) のもので、nagadomi 氏の waifu2x で拡大されています。このエディションで追加したのは、ほかと同じ方法で作ったポーランド語のコミック風パネル 4 枚だけです。

```
presplash.png    ロード画面
hd/              背景、立ち絵、CG、インターフェース、エフェクト、動画（patch-hd.rpa にまとめられます）
r18/             R18 シーンとその画像（r18-hd.rpa にまとめられます）
```

アートを更新するには、パッケージを `assets` フォルダに展開し、同じ名前とフォルダ構成のままファイルを
置き換えるか追加して、ビルドを実行します。共有する場合は、フォルダをもう一度 zip にしてリリースに
アップロードしてください。

## テストとフィードバック

このパッチは Ren'Py の lint で、未改変の Steam 版と同じ警告しか出ません。メニュー、設定、セーブ画面、
ギャラリー、オープニング、いくつかの本編と R18 のシーンをゲーム内で確認し、すべてのシーン命令と画像の
定義をオリジナルの HD パッチと比較しました。とはいえ『かたわ少女』は長いゲームで、すべてのルートと言語の
すべてのシーンをプレイしたわけではないため、**さらなるテストが必要です**。テストは Windows でしか行って
いないので、Linux と macOS のプレイヤーからの報告は特に歓迎します。

立ち絵の位置ずれ、CG の切れ、UI のずれなどの問題を見つけたら、シーン、言語、できればスクリーンショットを
添えて issue を作成してください。コントリビューションも歓迎します。
