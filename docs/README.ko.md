**Steam판 Katawa Shoujo를 1920×1080 와이드 화면으로. R18 포함.**

Four Leaf Studios의 비주얼 노벨 **Katawa Shoujo(카타와 쇼죠)** Steam판을 원래의 800×600(4:3) 대신
**풀 HD(1920×1080, 16:9 와이드)**로 실행하게 해 주는 비공식 팬 패치입니다. 배경, 캐릭터 스프라이트, CG,
인터페이스, 영상을 HD 버전으로 교체합니다. Steam판의 Ren'Py 6.16 엔진에서 11개 언어 모두 지원합니다.

**[최신 버전 다운로드](https://github.com/ohshya/KatawaShoujoSteamHD/releases/latest)**

> 이 패치는 **letow**의 [Katawa Shoujo HD Patch](https://github.com/letow/KatawaShoujoHDPatch)를 이식한 것입니다.
> HD 아트워크(배경, 스프라이트, CG, UI, 효과, 영상)는 모두 그 프로젝트에서 가져왔습니다. 전체 크레딧은 마지막에
> 있습니다.

## 이번 에디션의 새로운 점

원본 HD 패치에는 없는, 이번 에디션만의 기능입니다.

- **Steam판의 11개 언어 전부.** 원본 패치는 영어, 스페인어, 프랑스어, 일본어를 지원했고 독일어와 러시아어는
  추가 언어였습니다. 이번 에디션은 한국어, 폴란드어, 브라질 포르투갈어, 중국어 간체와 번체를 추가했으며,
  각 언어의 R18 장면도 포함합니다. 원본 패치에 없던 폴란드어 만화 패널 4개(`comic_vfx*_pl`)도 다른 언어와
  같은 방식으로 HD로 만들었습니다.
- **Steam판 지원.** HD 조정(해상도, 위치, 줌, 팬, UI 레이아웃)을 Steam판 스크립트를 교체하지 않고 그 위에
  적용하므로 업적, 컨트롤러 지원, R18 설정, 압축된 언어 파일 같은 Steam판 기능이 그대로 작동합니다.
- **HD R18 패치.** `r18-hd.rpa`가 공식 `r18.rpa`를 대신하며 같은 장면을 HD로 담고 있습니다.
- **스크롤되는 언어 선택 화면.** HD 레이아웃을 유지하면서 11개 언어가 모두 들어가도록 스크롤됩니다.
- **화면에 맞는 창.** 게임은 바탕 화면의 사용 가능한 영역(작업 표시줄과 제목 표시줄 제외)의 90% 크기로
  가운데에 창으로 열립니다. 크기는 1280×720에서 1920×1080 사이이며 화면보다 커지지 않습니다. 전체 화면은
  이전과 똑같이 작동합니다.
- **더 새로운 게임 기반.** Katawa Shoujo 1.3/1.3.1 대신 현재 Steam판 스크립트(v1.3.2)를 기반으로 하므로
  이후의 게임 수정 사항이 유지됩니다.
- **개별 파일 대신 아카이브.** HD 리소스는 `.rpa` 아카이브 2개로 제공되므로 패치를 설치하고 제거할 때는
  파일을 추가하거나 삭제하기만 하면 됩니다.

## 설명

원본 HD 패치는 성인용 콘텐츠가 게임 안에 포함된 Katawa Shoujo StandAlone판(Ren'Py 6.10)용으로
만들어졌습니다. Steam판은 더 새로운 Ren'Py(6.16.5)에서 실행되고, 그 콘텐츠를 원래의 4:3 아트 그대로 별도의
R18 패치(`r18.rpa`)로 분리했으며, 자체 기능도 추가했습니다. 그래서 원본 패치를 Steam판에 적용하면 게임이
멈춥니다.

이번 에디션은 같은 HD 리마스터를 Steam판에 적용하고 R18 패치도 HD로 포함합니다.

### 시각적 변경 사항

이번 에디션은 코드 이식만 한 것으로 새로운 시각적 변경은 없으며, 게임은 원본 HD 패치를 적용했을 때와 똑같이 보입니다. 적용 전/후 비교는 [원본 Katawa Shoujo HD Patch 저장소](https://github.com/letow/KatawaShoujoHDPatch)에서 볼 수 있습니다.

## 설치

설치 프로그램은 필요 없습니다.

> **패치는 [Releases](https://github.com/ohshya/KatawaShoujoSteamHD/releases/latest) 페이지에서 받으세요.**
> 저장소에는 빌드 도구가 들어 있으며, HD 아카이브(약 660MB인 `patch-hd.rpa`와 `r18-hd.rpa`)는 릴리스 zip에만
> 있습니다.

1. 최신 릴리스에서 [`KS-HD-1.0.1-Steam-Patch.zip`](https://github.com/ohshya/KatawaShoujoSteamHD/releases/download/v1.0.1/KS-HD-1.0.1-Steam-Patch.zip)을 받습니다.
   게임을 하는 데 필요한 파일은 이것 하나뿐입니다. 다른 하나인 `Assets-For-Building-Only`는 패치를 직접
   빌드할 때만 씁니다.
2. Steam에서 **Katawa Shoujo**를 마우스 오른쪽 버튼으로 클릭하고 **관리** > **로컬 파일 보기**를 선택합니다.
3. zip을 그 폴더(`Katawa Shoujo.exe`가 있는 폴더)에 압축 해제합니다.
4. 물어보면 **모든 파일 바꾸기**를 선택합니다.
5. Steam에서 게임을 실행합니다.

**Linux와 macOS:** 패치는 게임 데이터(스크립트와 아카이브)만 교체하며, 이는 모든 시스템에서 같습니다.
Linux에서는 과정이 똑같습니다. macOS에서는 **로컬 파일 보기**를 누르면 게임 앱이 있는 폴더가 열립니다. 앱을
마우스 오른쪽 버튼으로 클릭해 **패키지 내용 보기**를 선택하고, zip의 `game` 폴더를 그 안의 `game` 폴더에
합치세요.

공식 `r18.rpa`는 필요 없습니다. 이미 폴더에 있다면 그대로 두어도 되며, 게임은 HD 버전을 사용합니다.

**제거 방법:** `game/patch-hd.rpa`와 `game/r18-hd.rpa`를 삭제한 다음, Steam에서
**속성** > **설치된 파일** > **게임 파일 무결성 확인**을 실행합니다.

> Steam 업데이트로 패치된 스크립트가 덮어써질 수 있습니다. 그런 경우 패치를 다시 압축 해제하세요.

> **Steam의 기본 브랜치를 사용하세요.** 이 패치는 게임의 기본 버전(Ren'Py 6.16)용입니다. 베타인
> **modern - Ren'Py 8 branch**에서는 아직 작동하지 않습니다. 이 베타를 선택했다면 패치를 설치하기 전에
> **속성** > **베타**에서 기본 브랜치로 돌아가세요. Ren'Py 8 브랜치 지원은 현재 작업 중입니다.

## 자주 묻는 질문

**Steam의 "modern - Ren'Py 8 branch"에서도 작동하나요?**
아직은 아닙니다. 지원 작업을 진행하고 있습니다. 패치는 기본 브랜치(Ren'Py 6.16)용이며, Ren'Py 8 베타는
스크립트 형식이 달라서 거기에 설치하면 게임이 망가집니다.

**공식 R18 패치(`r18.rpa`)가 필요한가요?**
아니요. `r18-hd.rpa`에 R18 장면이 이미 HD로 들어 있으며, 게임에서 이를 끄는 옵션도 그대로 작동합니다.

**letow의 Katawa Shoujo HD Patch와 같은 것인가요?**
같은 HD 아트와 장면 조정을 Steam판으로 이식했으며, 여기에 "이번 에디션의 새로운 점"의 변경 사항이 더해졌습니다.
letow의 원본 패치는 StandAlone판용이라 Steam판에서는 멈춥니다.

**Linux, macOS, Steam Deck에서도 작동하나요?**
작동할 것입니다. 패치는 모든 시스템에서 똑같은 게임 데이터만 바꿉니다. 다만 지금까지는 Windows에서만
테스트했으므로 제보를 환영합니다.

**원래 게임으로 돌아가려면 어떻게 하나요?**
`game/patch-hd.rpa`와 `game/r18-hd.rpa`를 삭제한 다음, Steam에서 **게임 파일 무결성 확인**을 실행합니다.

## 소스에서 빌드하기

저장소에는 패치를 만드는 코드가 들어 있습니다. 데이터로 저장한 HD 변경 사항과, 이를 여러분의 게임 사본에
적용하는 도구입니다. 게임 파일과 HD 아트는 포함되어 있지 않습니다.

이 도구는 투명성을 위한 것으로, 누구나 패치가 무엇을 바꾸는지 정확히 확인하고 다시 빌드할 수 있게 합니다.
HD 패치를 이식하려면 Katawa Shoujo StandAlone판, Steam판, 공식 `r18.rpa`, StandAlone판용 HD 패치에서 정보를
추출하고 서로 비교해 HD 패치의 변경 사항을 모두 찾아야 했습니다. 이 추출 모듈은 한 번만 필요했기 때문에
포함하지 않았고, 그 결과를 `kshd/edits`에 저장했습니다.

### AI 사용

이식 작업 자체는 길고 정리되지 않은 과정이었으며, 버리는 테스트 코드와 실험이 엄청나게 많았습니다. 그 과정에서
직접 손으로 작성한 원래의 도구를 공개하는 것은 현실적이지 않았고 의미도 없었습니다. 대신 이 저장소의 빌드
도구는 이식 작업으로 얻은 데이터로 패치를 깔끔하고 확실하게 빌드할 수 있도록 Anthropic의
**Claude(Opus 5.5)**로 만들었습니다.

### 요구 사항

- [Python](https://www.python.org/) 3.9 이상. 추가 패키지는 필요 없습니다.
- **수정하지 않은** 기본 브랜치의 Steam판 Katawa Shoujo(Ren'Py 8 베타 제외).
- HD 리소스 패키지: [`KS-HD-1.0.1-Assets-For-Building-Only.zip`](https://github.com/ohshya/KatawaShoujoSteamHD/releases/download/v1.0.1/KS-HD-1.0.1-Assets-For-Building-Only.zip) (약 700MB).

### 빌드

1. 이 저장소를 클론하거나 내려받습니다.
2. 다음 두 가지 방법 중 하나로 도구가 게임을 읽을 수 있게 합니다.
   - **저장소 안에 게임 사본 두기:** 게임 폴더(`Katawa Shoujo.exe`가 있는 폴더)를 저장소 최상위에 복사하고
     이름을 `Katawa Shoujo`로 바꿉니다. 패치를 설치하기 전에 만든 사본을 사용하세요. 이 방법을 쓰면 Steam
     설치본에 패치를 적용한 채로 빌드할 수 있습니다.
   - **Steam 설치본 사용:** 저장소에 사본이 없으면 도구가 Steam 라이브러리에서 게임을 찾습니다. 이미 그곳에
     이 패치를 설치했다면 먼저 Steam에서 **게임 파일 무결성 확인**을 실행하세요.
3. `KS-HD-1.0.1-Assets-For-Building-Only.zip`을 `assets` 폴더에 넣습니다(압축된 상태든 푼 상태든 상관없습니다).
4. 다음을 실행합니다.

```bash
python build.py
```

도구가 스크립트에 패치를 적용하고 `build.py` 옆에 `KS-HD-1.0.1-Steam-Patch.zip`을 만듭니다. 이 zip이 패치이며,
"설치"에 설명한 대로 설치하면 됩니다.

스크립트가 패치가 예상하는 내용과 다르면 빌드가 멈추고 어떤 스크립트인지 알려 줍니다. 게임 파일이 수정되었거나
다른 버전일 때 이런 일이 생깁니다.

### 작동 방식

HD 패치가 게임 스크립트에서 바꾸는 것은 해상도, 위치, 줌, 팬, 인터페이스 레이아웃, 그리고 "이번 에디션의
새로운 점"에서 설명한 창 크기뿐입니다. 이 변경 사항은 스크립트마다 JSON 파일 하나씩, 읽을 수 있는 데이터로
`kshd/edits`에 저장되어 있습니다.

- **`code`**: 인터페이스 코드 교체. 각각 정확한 원래 텍스트와 나타나야 하는 횟수를 담고 있어, 다른 버전의
  게임에 잘못 패치하는 대신 이를 감지합니다.
- **`nodes`**: 장면 명령(`show`, `scene`, ATL 변환)의 변경. 레이블과 원래 내용으로 위치를 찾기 때문에 같은
  파일로 11개 언어 모두에 쓸 수 있습니다.

| 파일 | 역할 |
|---|---|
| `build.py` | 게임과 리소스를 찾고, 스크립트에 병렬로 패치를 적용해 패치 zip을 만듭니다. |
| `kshd/edits/*.json` | 데이터로 저장한 HD 변경 사항. |
| `kshd/patch.py` | 변경 사항 파일을 스크립트에 적용합니다. |
| `kshd/tree.py` | 스크립트 구조를 따라가며 바꿀 코드와 명령을 찾습니다. |
| `kshd/rpyc.py` | 컴파일된 `.rpyc` 스크립트를 Ren'Py 6.16과 호환되도록 읽고 저장합니다. |
| `kshd/rpa.py` | Ren'Py `.rpa` 아카이브를 읽고 씁니다. |

### HD 리소스 패키지

이미지, 영상, R18 장면은 코드와 분리된 리소스 패키지에 들어 있어 코드를 건드리지 않고 개선할 수 있습니다. HD 아트는 letow의 [Katawa Shoujo HD Patch](https://github.com/letow/KatawaShoujoHDPatch)에서 가져왔으며 nagadomi의 waifu2x로 업스케일되었습니다. 이번 에디션에서 추가한 것은 다른 것과 같은 방식으로 만든 폴란드어 만화 패널 4개뿐입니다.

```
presplash.png    로딩 화면
hd/              배경, 스프라이트, CG, 인터페이스, 효과, 영상(patch-hd.rpa로 묶임)
r18/             R18 장면과 그 이미지(r18-hd.rpa로 묶임)
```

아트를 업데이트하려면 패키지를 `assets` 폴더에 풀고, 같은 이름과 폴더 구조를 유지한 채 파일을 바꾸거나
추가한 다음 빌드하세요. 공유하려면 폴더를 다시 zip으로 묶어 릴리스에 올리면 됩니다.

## 테스트와 피드백

이 패치는 Ren'Py의 lint에서 수정하지 않은 Steam판 게임과 같은 경고만 나옵니다. 메뉴, 설정, 저장 화면, 갤러리,
오프닝, 여러 스토리 장면과 R18 장면을 게임에서 확인했고, 모든 장면 명령과 이미지 정의를 원본 HD 패치와
비교했습니다. 하지만 Katawa Shoujo는 긴 게임이라 모든 루트와 언어의 모든 장면을 플레이해 보지는 못했으므로
**더 많은 테스트가 필요합니다**. Windows에서만 테스트했기 때문에 Linux와 macOS 플레이어의 제보를 특히
환영합니다.

스프라이트 위치가 틀렸거나, CG가 잘렸거나, UI 요소가 어긋났거나, 그 밖의 문제를 발견하면 장면, 언어,
가능하다면 스크린샷을 첨부해 issue를 열어 주세요. 기여도 환영합니다.
